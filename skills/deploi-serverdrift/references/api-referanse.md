# Deploi API-referanse – startpunkt

- Offisiell dokumentasjon: deploi.no (fasit – denne filen er kun et startpunkt).
- Autentisering skjer med personlig token i miljøvariabel (`DEPLOI_TOKEN`).
  Tokenet skal aldri limes inn i chat eller committes til git.
- Typiske operasjoner: liste servere, opprette server, deploye app,
  lese logger, administrere DNS.
- Verifiser eksakte kommandoer og endepunkter mot gjeldende dokumentasjon
  før hvert oppdrag – CLI og API endres over tid.
- Norske datasentre: bekreft plassering med leverandøren dersom datasuverenitet
  er et krav i prosjektet.
