# Matrikkelfelt – hurtigreferanse

Et matrikkelnummer bygges opp slik: `Kommunenummer-Gnr/Bnr/Fnr/Snr`.

| Felt | Betydning |
|---|---|
| Knr | Kommunenummer (4 siffer) |
| Gnr | Gårdsnummer |
| Bnr | Bruksnummer |
| Fnr | Festenummer (0 = ingen feste) |
| Snr | Seksjonsnummer (eierseksjoner, 0 = ingen) |
| Skyldmark | Historisk skylda verdi – sier lite om dagens markedsverdi |
| Bruksenhet | Bolig-/næringsenhet innenfor eiendommen (f.eks. H0101) |

Kilder for verifisering: Seeiendom for visuelt oppslag, SSR for offisielle
stedsnavn, grunnboken for tinglyste rettigheter. API-endepunkter for maskinelle
oppslag verifiseres mot Kartverkets og Geonorges dokumentasjon.
